# LOOM 2.3.27 更新说明

## 自动更新交接

- 修复点击“立即重启”后界面没有反应、重新打开仍是旧版本的问题。
- 更新接管进程会先写入就绪握手，LOOM 确认接管成功后才关闭当前版本。
- 后台服务停止改为异步执行，并设置有限退出时间，Bridge 响应缓慢时不再卡住重启按钮。
- 接管进程与当前应用脱离，不会随 LOOM 主进程退出而被系统一并结束。

## 安装与恢复

- 修复安装目录包含空格或中文时 `/D=` 参数被拆分、安装到错误位置的问题。
- 正确等待 NSIS 安装器主进程结束，同时避免被安装器启动的运行时子进程长期阻塞。
- 更新失败时保留当前版本和已校验安装包，并在界面中显示可直接运行的本地安装包路径。
- 保留更新前数据备份、安装后健康检查和失败自动回滚能力。

## 升级说明

- 未触发旧版重启故障的设备可以继续尝试应用内更新。
- 若旧版本已经停在“更新已准备好”且点击“立即重启”无反应，请完全退出 LOOM，手动运行 `%LOCALAPPDATA%\LOOM-Update-Recovery\updates` 中已下载的官方安装包完成一次过渡。
- 安装 `2.3.27` 后，后续版本恢复应用内下载、校验、重启安装和失败回滚的完整一键更新流程。
