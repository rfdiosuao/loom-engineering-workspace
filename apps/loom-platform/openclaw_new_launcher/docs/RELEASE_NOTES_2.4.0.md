# LOOM 2.4.0 更新说明

## 手机配对与稳定性

- 手机端不再要求用户手工配置长期 API Token，改为 6 位一次性配对码和完整局域网配对信息。
- 长期设备凭据由电脑与手机自动交换，并使用 AndroidKeyStore 支持的 AES-GCM 加密保存，不在界面、日志和接口响应中回显。
- 增加配对码过期、重放、暴力尝试、传输通道绑定和限流保护；USB 与局域网断线后可恢复，不回退到明文凭据。
- 手机状态、矩阵截图与任务执行继续共用同一设备身份和恢复链，减少“手机仍在执行、桌面误报失败”的情况。

## 中枢智能体

- 强化运行规划、工具调用、终态收敛、暂停、取消、重试和断线续跑，工具事件按一次运行聚合，避免调用卡片刷屏。
- 加固会话持久化、短期记忆、审批恢复、模型路由和失败降级；审计写入异常不再覆盖真实任务结果。
- 智能体、矩阵与手机控制使用同一能力注册表和精确设备作用域，历史能力 ID 保持兼容。

## Skill 与 Agent 接入

- Skill 包改为确定性构建，同一源码生成相同 SHA256；安装过程增加并发锁、崩溃恢复和目录所有权保护。
- 国内网络优先使用 Gitee 下载，GitHub 作为回退，并支持离线本地路径。
- 发布流程先上传签名更新清单，再发布 Skill 和大文件，避免客户端读取到尚未完整发布的版本。

## 界面与可用性

- 总览、安装、智能体、创作、获客、矩阵、模型、设置和诊断统一使用语义化状态色与表面层级。
- 修复暗色悬停对比度、低高度授权页裁切、USB 选择器标签、弹窗焦点陷阱与焦点恢复。
- 区分弹窗遮罩和右上角关闭按钮的无障碍名称，避免辅助技术识别出两个同名控制。

## 发布质量

- 桌面端升级到 `2.4.0`，手机端升级到 `6.63-stability`（`versionCode 932`）。
- 全量 Python、前端、Node、Rust、Android、工作区治理和三种桌面尺寸 E2E 均纳入发布门禁。
- Playwright 在 Windows 上直接托管 Vite，并将慢速环境的单场景预算调整为 60 秒，减少残留进程和误报超时。
