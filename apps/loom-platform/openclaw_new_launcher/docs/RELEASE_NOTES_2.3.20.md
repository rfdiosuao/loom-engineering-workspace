# LOOM 2.3.20 更新说明

## 模型配置兼容性

- 修复部分中转站模型能够出现在模型列表中，但实际不支持 Codex 所需 `Responses API`，导致配置写入后仍无法使用的问题。
- 配置验证现在区分 API Key 无效、模型无权限、模型不兼容、服务限流、上游故障和网络不可达。
- 模型不兼容时不再显示难以理解的原始 `404/openai_error`，而是提供中文原因和明确处理动作。
- 增加“重新选择模型”和“检查 API Key”入口，配置失败时不会写入不可用配置。
- 系统日志保留脱敏后的技术细节，界面不再暴露冗长上游错误。

## 安装与更新

- 便携版首次启动时能够检测并引导安装 Microsoft Edge WebView2 Runtime，减少新电脑白屏或无法启动。
- 更新清单未配置下载地址时不再写入空 URL，避免客户端获得无效更新任务。
- 修复平台工具在 Windows PowerShell 5.1 下的编码与脚本兼容问题。
- 发布检查会在 Rust 构建前准备所需运行时资源，减少 CI 与本地打包结果不一致。
- 加固 Windows 发布测试夹具，避免系统模块和临时可执行文件污染验证结果。

## 升级说明

- 支持从 `2.3.19` 直接覆盖升级。
- 用户配置、模型账号、手机配置、历史会话和本地素材保持不变。
- 已经写入但无法使用的模型配置，升级后请重新执行一次“写入配置”，LOOM 会给出具体兼容性结论。
- 正在执行的手机或矩阵任务建议完成或停止后再升级。
