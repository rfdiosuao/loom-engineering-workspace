# 麓鸣 2.4.7 / LumiAgent 6.67 发布说明

> 配套版本：麓鸣 Desktop `2.4.7`；LumiAgent `6.67-stability`（Android 7 为
> `6.67-stability-android7`）；手机 versionCode `936`。本次不修改手机端。

## 模型账户与支付状态修复

- 创建订单和查询订单使用独立状态；只有当前选择的套餐显示“正在创建订单”。
- 支付成功、账号切换或在线状态失效后会释放支付状态，避免永久停留在“查询中”。
- 模型订阅兼容接口共享约 3 秒总请求预算；线路异常时返回安全缓存快照，不再串行等待多个 20 秒超时。
- 支付开通仍只以服务端验签通知和原生订单状态为准，模型订阅不会解锁矩阵授权。
- 服务端 USD 标价继续按产品约定名义 1:1 显示为人民币，不做实时汇率换算。
- 支付商户配置默认关闭；发布包不携带支付密钥，也不执行真实支付。

## 手机能力边界

- LumiAgent 保持 `6.67-stability`，versionCode `936`；本次没有修改或重新构建 APK。
- 手机低延迟视频、Shizuku 和 PRoot/Linux companion 行为保持不变。
- PRoot/Linux 仍由独立安装的 companion 提供，主 APK 不内置 PRoot。
- companion 仍需独立安装；Shizuku 授权不等于 Shizuku 服务正在运行。

## 发布和验收

- Windows 安装包通过 LOOM Ed25519 签名的自动更新清单进行完整性和来源校验。
- 自动化不能替代真实模型账号、服务端支付回调和实体机验收。
