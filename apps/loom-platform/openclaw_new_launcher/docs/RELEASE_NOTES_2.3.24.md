# LOOM 2.3.24 更新说明

## 国内自动更新

- 正式安装包新增国内高速分片镜像，客户端按分片断点续传，改善 GitHub Release 在国内网络下载缓慢或中断的问题。
- 每个分片的地址、序号、大小和 SHA256 都写入 Ed25519 官方签名清单，下载后先逐片校验，再合并并校验完整安装包。
- 国内镜像不可用、内容损坏或连接中断时，自动回退 GitHub 官方完整安装包；任何校验失败都不会进入安装。
- 发布流水线必须先完成全部国内分片上传并取得 API 成功回执，之后才允许发布 GitHub 正式版本，避免清单存在但镜像缺失。
- 保留取消下载、断点续传、无损升级、进程安全交接、升级健康检查和失败回滚。

## 模型与智能体稳定性

- 修复 Claude Code 在 Windows 上被错误启动为不兼容可执行文件的问题，统一使用 npm 生成的命令入口。
- 模型上游返回 `404`、`5xx` 或网络错误且尚未产生输出时，原生智能体可在同一模型账号内安全切换到可用文本模型。
- 模型配置验证明确区分“上游未开放该模型”和“LOOM 配置写入失败”，不会用上游通道缺失冒充本地写入故障。
- 修复图片或视频任务快速失败后仍持续显示“正在生成”的轮询竞态。

## 升级说明

- `2.3.23` 可直接在应用内更新到 `2.3.24`。首次进入新分片更新通道时仍需获取本次完整安装包；从 `2.3.24` 开始，后续版本默认使用国内高速镜像。
- `2.3.17` 等未内置当前 Ed25519 更新公钥的旧版本无法信任新签名，需要从官方发布页手动安装一次最新版。升级会保留用户配置、模型账号、历史会话、手机配置和本地素材。
