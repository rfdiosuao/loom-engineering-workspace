# LOOM 2.3.25 更新说明

## 自动更新

- 最新版本发现改为 Gitee 国内源、GitHub 稳定清单和 GitHub API 三源容灾。
- 瞬时断线、限流和服务器错误会有限重试，不再因一次连接重置直接结束更新。
- 国内镜像只需托管签名清单和分片即可被客户端识别，不再强制上传完整安装包。
- 发布流程会先上传 Ed25519 签名清单，再并行上传 4 个更新分片，并在结束后核对国内镜像附件完整性。
- 国内镜像上传窗口由 10 分钟提高到 30 分钟，避免慢速网络下最后一个分片被提前终止。
- 每个分片支持 Gitee 主源、GitHub 自动回退、断点续传和独立 SHA256 校验。
- 4 个分片最多 4 路并行下载，合并后再次校验完整安装包 SHA256 和官方发布签名。
- GitHub Release 同时发布稳定清单直链，GitHub API 不可用时仍可发现新版本。

## 智能体与模型

- 修复 Claude Code 安装后误启动 npm 文本包装器而出现“不支持的 16 位应用程序”。
- 写入模型配置时会识别上游未开放、协议不兼容和临时不可用的模型，不再把失败配置写成成功。
- 智能体对同一模型账户启用安全候选回退，并保留实际失败原因与可行动建议。
- 模型超时后停止继续调用新工具，避免任务刷屏和重复副作用。

## 创作

- 修复生图任务快速完成时轮询状态覆盖最终结果的问题。
- 对上游 404、503、524、模型未开放和登录缺失返回明确中文错误，不再长期停留在“正在生成”。

## 升级说明

- `2.3.24` 可直接在应用内更新到 `2.3.25`。
- `2.3.17` 至 `2.3.20` 若提示旧签名无效，需要从官方发布页手动安装一次 `2.3.25`，建立新的更新公钥信任链；此后即可继续自动更新。
