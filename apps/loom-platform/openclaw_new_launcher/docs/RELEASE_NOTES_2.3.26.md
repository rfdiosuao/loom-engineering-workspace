# LOOM 2.3.26 更新说明

## 自动更新可靠性

- 更新安装包和每个分段均支持同一下载源最多 3 次有限重试，瞬时超时或连接重置不再立即终止更新。
- 下载过程中断后会在当前更新操作内自动携带 `Range` 续传，不需要用户关闭弹窗后重新开始。
- 服务端拒绝旧断点或返回错误分段范围时，会自动清理无效缓存并从头恢复下载。
- 国内镜像分段下载失败后仍会自动切换 GitHub 备用源；备用源发生瞬时故障时同样会重试。
- HTTP 403 等非瞬时权限错误继续按真实原因呈现，不会被误报为可重试的网络中断。

## 国内更新镜像

- 修复 Gitee 附件配额超过 1 GB 后新版本首个分段无法上传的问题。
- 发布新版本时先保留签名清单并清理旧桌面镜像，再并行上传当前版本分段。
- 上传完成后必须核对签名清单及全部分段，缺少任一文件都会明确标记镜像发布失败。

## 已包含修复

- 包含 Claude Code Windows 启动兼容、模型可用性探测与安全回退、智能体超时停止调用工具等修复。
- 包含生图任务完成态保护，以及上游 404、503、524、模型未开放和登录缺失的中文错误提示。

## 升级说明

- `2.3.24` 和 `2.3.25` 均可直接在应用内更新到 `2.3.26`。
- `2.3.17` 至 `2.3.20` 若提示旧签名无效，需要先手动安装一次新版本，建立新的更新公钥信任链。
