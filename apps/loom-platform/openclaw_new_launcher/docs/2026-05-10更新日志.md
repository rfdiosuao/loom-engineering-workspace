# 2026-05-10 更新日志

> 范围：LOOM 启动器、APKClaw 手机端与智能体便携工作区。

本次更新补齐了“电脑生成图片、传入手机相册、再由智能体继续处理”的基础闭环，并加强了便携包的能力说明与交付校验。

## 核心成果

- APKClaw 手机端更新至 `6.11`，`versionCode=710`。
- 新增电脑图片导入手机相册能力，支持启动器 UI、CLI 与手机端 API。
- 智能体启动时可读取能力清单、角色说明、工具说明和 Skills。
- 智能体运行上下文保持品牌中性，便于同一套能力适配不同发行版本。
- 打包流程开始校验智能体工作区、运行时上下文和手机端相关资源。

## APKClaw 手机端

- 新增 `POST /api/media/import_image`。
- 支持通过 `multipart/form-data` 上传 PNG、JPEG 和 WebP 图片。
- 单文件最大 32 MB。
- 接口沿用 `X-AGENT-PHONE-TOKEN` / `X-APKCLAW-TOKEN` 鉴权。
- 错误令牌返回 `401`，无效图片返回明确错误。

## LOOM 启动器

- AI 生成图片保存到 `data/generated-images/`。
- 生图页面新增“生成后发送手机相册”能力。
- 新增 `scripts/openclaw-image-phone.mjs`，可生成图片后上传手机，或上传已有本地图片。
- `phone:image` CLI 支持 JSON 输出以及图片模型、输出目录、手机地址、令牌和相册名等参数。
- 新增 `openclaw:context` CLI，用于生成智能体运行时上下文。
- 手机连接配置可同步给智能体运行时使用，但上下文文件不写入明文令牌。

## 智能体便携工作区

便携工作区包含以下核心说明：

- `AGENTS.md`
- `SOUL.md`
- `TOOLS.md`
- `CAPABILITIES.md`
- `runtime-context.json`
- 手机控制和图片传输相关 Skills

这些文件用于让智能体在启动后主动发现 LOOM 能力，不依赖用户重复描述。

## 验证重点

- 图片生成后能够保存到本地素材目录。
- 图片能够通过受保护接口导入手机相册。
- 运行时上下文不泄露手机令牌或模型密钥。
- 公开交付包不包含用户日志、会话状态或真实设备配置。
