# LOOM 2.3.23 更新说明

## 自动更新

- 更新发现优先通过 GitHub Assets API 获取官方签名清单，绕开部分国内网络对 GitHub Release 附件入口的连接超时。
- 正式安装包同样优先使用 Assets API，并保留原发布页下载地址作为自动回退。
- Assets API 不可用、限流或连接失败时，更新器会继续尝试原下载地址，不会因为单一入口故障直接判定没有更新。
- API 与原下载地址使用同一份正式发布资产；下载后仍执行文件大小、SHA256 和 Ed25519 官方签名三重校验。
- 断点续传、取消后保留进度、无损升级、健康检查和失败回滚链路保持不变。

## 2.3.22 累积修复

- 修复 Claude Code 在 Windows 上被错误识别为 16 位程序的问题。
- 原生智能体在文本模型首次输出前遇到上游 `404`、`5xx` 或网络故障时，可在同一模型账号内安全回退到可用文本模型。
- 修复图片或视频任务快速失败后页面持续显示“正在生成”的轮询竞态。
- 发布流程强制校验 Ed25519 私钥与客户端更新公钥一致，阻止签名不匹配的安装包发布。

## 升级说明

- `2.3.20` 及以上版本可通过应用内更新中心升级；网络环境无法稳定访问 GitHub Release 附件时，建议手动安装一次 `2.3.23`，后续版本即可使用新的双通道更新能力。
- `2.3.17` 等尚未内置当前更新公钥的旧版本，需要从官方发布页手动安装一次最新版；用户配置、模型账号、历史会话、手机配置和本地素材保持不变。
