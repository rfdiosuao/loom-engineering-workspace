# LOOM 2.3.19 更新说明

## 安装与组件管理

- 修复 Codex、Claude Code 等组件需要跳转人工安装时，任务仍持续轮询并最终超时的问题。
- Microsoft Store 已打开或需要用户操作时，任务会进入“等待人工完成”状态，不再伪装成后台安装中。
- 增强 Claude Code、opencode、OpenClaw 和 Hermes 的真实版本探测。
- 组件入口不可执行时立即停止启动，并显示故障阶段与可操作的修复建议。

## 中枢智能体

- 修复人工处理任务无法正常结束，导致界面长时间显示执行中的问题。
- 智能体现在能够正确识别“需要人工处理”，不会将其误报为成功或普通失败。
- 优化模型服务 `401/403` 鉴权错误分类，明确区分未登录、登录失效和第三方模型配置异常。

## 全案九步

- 修复未登录模型账号时，全案生成接口连续写入完整 traceback、造成系统日志刷屏的问题。
- 未登录时返回明确中文提示，并引导用户打开“模型账号”完成登录。
- 模型账号登录失效时显示重新登录提示，不再返回笼统的服务器内部错误。
- 系统日志改为单行结构化诊断，包含生成阶段、错误码、HTTP 状态和建议动作，不再记录预期业务异常的堆栈。

## 手机与矩阵

- 手机任务达到执行轮次上限时，不再直接判定为彻底失败。
- 保留手机端已经完成的操作与部分结果，并标记为“需要检查”。
- 矩阵工作台同步显示人工接管状态，便于决定继续任务、重试或停止。
- 改进设备异常信息，减少“任务执行失败但不知道原因”的情况。

## 日志与诊断

- 日志导出增加 UTF-8 BOM，改善 Windows 记事本和表格软件的中文兼容性。
- 预期业务错误使用精简结构化日志，未知异常继续保留完整 traceback 便于开发定位。
- 错误响应包含错误码、故障阶段、是否可重试、处理建议和任务保留状态。
- 区分模型鉴权、组件缺失、人工安装、手机执行上限与设备连接异常。
