# LOOM 2.4.1 更新说明

## 安全与鉴权

- 手机配置、调试与截图接口统一要求设备令牌，敏感频道配置不再明文返回。
- 调试文件访问增加规范路径边界校验，发布构建默认禁止 Android 明文网络流量。
- QQ 登录日志不再记录访问令牌、授权头或敏感响应正文。
- License 服务增加请求体上限、读取超时与可信代理白名单，并以低权限账户运行。

## 稳定性

- 模板云数据库写入改为进程内加锁、唯一临时文件、落盘同步与原子替换；损坏数据不再被静默覆盖。
- Storyboard 生成接口补齐鉴权，未授权请求返回 401。
- 修复 Dashboard 发布契约，补齐总览主视觉、入口标签与移动端可访问性信息。

## 依赖与质量

- 将 `brace-expansion` 安全覆盖版本升级到 `5.0.9`，npm 审计为 0 个已知漏洞。
- 完成前端、Python、Rust、Android、工作区与高风险回归门禁验证。
- 桌面端版本升级到 `2.4.1`。
