# 麓鸣 2.4.8 / LumiAgent 6.67 发布说明

> 配套版本：麓鸣 Desktop `2.4.8`；LumiAgent `6.67-stability`（Android 7 为
> `6.67-stability-android7`），手机 versionCode `936`。本次不修改或重新构建手机端。

## ZPay 充值闭环修复

- 账号资料暂时使用安全快照时，支付服务仍会独立在线验证套餐和收款渠道。
- 套餐目录与订单创建、查询和恢复使用独立请求序列，避免并发状态相互覆盖。
- 应用重启后恢复未完成订单并复用幂等请求标识，不重复创建订单。
- Bridge 将超时 pending 订单收敛为 expired；服务端随后确认真实到账时仍可更新为 paid。
- 客户端显示 ZPay 已就绪、在线充值未启用、支付配置未确认或无可用渠道等准确状态。

## 收款和安全边界

- 模型订阅使用 New API 原生 EPay → ZPay 权威链路。
- PID、Key、签名字段和服务端令牌不进入客户端、普通日志或安装包。
- 支付成功只以服务端异步通知和原生订单状态为准；前台返回页不直接发放订阅。
- 商业矩阵授权与模型订阅保持独立，不因模型充值自动解锁矩阵设备权益。

## 发布与验收

- 生产 Bridge 已完成受控部署和自动备份，环境配置在部署过程中保持不变。
- 自动化覆盖套餐加载、扫码创建、幂等恢复、订单过期和支付状态诊断；自动化不替代真实商户小额验收。
