# 麓鸣 2.4.9 / LumiAgent 6.67 发布说明

> 配套版本：麓鸣 Desktop `2.4.9`；LumiAgent `6.67-stability`（Android 7 为
> `6.67-stability-android7`），手机 versionCode `936`。本次不修改或重新构建手机端。

## 自动更新交接修复

- 修复旧版本启动升级交接进程后以 `exit code 0` 提前结束、安装包已下载但应用不退出的问题。
- 标准 `-File` 交接未生成就绪标记时，自动使用 UTF-16LE 编码命令进行一次兼容重试。
- 交接进程的标准输出和错误输出写入独立启动日志，失败弹窗直接给出日志路径。
- 保留原有外部备份、安装目录、数据恢复、健康确认和失败回滚机制。

## 商业矩阵授权修复

- 已登录账号即使当前显示上次安全快照，也可以输入商业矩阵授权码。
- 点击绑定后由在线授权服务验证账号和授权码，不再由缓存状态提前禁用输入框。
- 授权码继续使用密码输入模式，不回显、不写入普通日志；网络失败时保留输入内容以便重试。

## 余额金额显示

- 模型账户不再把 New API 内部 quota 数值直接当成 token 展示。
- 按生产计费配置 `500000 quota = ¥1.00` 显示可用余额和累计消费，统一保留两位小数。
- 请求次数继续独立展示，避免把调用次数、内部额度和真实 token 使用量混为一谈。

## 验收记录

- 前端生产构建、Rust 编译、账户与无损更新契约均通过。
- Windows 更新交接冒烟覆盖成功安装、旧进程退出、数据恢复、健康确认和失败回滚。
- 平台前端契约覆盖授权入口、支付入口、Agent、矩阵、手机连接和自动更新状态。
