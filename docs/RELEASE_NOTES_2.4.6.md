# 麓鸣 2.4.6 / LumiAgent 6.67 发布候选说明

> 当前配套版本：麓鸣 Desktop `2.4.6`；LumiAgent `6.67-stability`（Android 7 为
> `6.67-stability-android7`）；手机 versionCode `936`。

## 服务端原生订阅与应用内购买

- 麓鸣直接读取模型服务端的原生订阅套餐、当前订阅和订单状态，不再以本地默认值或只读快照冒充在线结果。
- 服务端 USD 标价采用产品约定的名义 1:1 人民币规则：数值 `50 USD` 在麓鸣中显示并创建为 `¥50.00`，不做实时汇率换算。
- 桌面端只向麓鸣后端创建请求；模型服务访问令牌、支付商 PID 与商户密钥均不会进入前端、普通日志或安装包。
- 支付商户配置默认关闭，只能由生产服务端环境显式启用；桌面候选包不携带商户密钥。
- 订单先持久化并使用幂等请求键；支付完成只以模型服务端原生回调和订单状态为准，同步返回页不能发放订阅。
- 模型订阅不会解锁矩阵授权。手机矩阵、基础获客、共享模板、飞书流转和 Skill 调用继续共用独立的 `matrix.devices` 商业授权。
- 本候选只验证套餐读取、订单合同和状态查询，不创建真实支付订单，不执行真实扣款、退款或结算。

## LumiAgent Linux companion 修复

- Skill 中心在缺少 Linux 运行时时提供可操作的下载安装流程，不再只显示 `companion_missing`。
- 下载固定使用 HTTPS，并在调起系统安装器前校验 APK SHA256、包名、最低版本和签名证书；临时文件采用原子落盘并限制大小。
- 安装未知来源权限或系统安装器返回后，Skill 中心会重新检测 companion，成功后自动初始化 PRoot/Alpine 并运行健康检查。
- PRoot/Linux 继续由独立安装的 `Lumi Linux Runtime` companion 提供，主 APK 不内置 PRoot 或 rootfs；companion 不申请 `INTERNET` 权限，只开放合同枚举的固定 Skill。
- Shizuku 保持用户主动授权的可选增强能力；拒绝、撤权或服务停止时回退标准模式，不开放任意 Shell。

## 既有能力与边界

- 用户界面只保留 `Codex Desktop`，Microsoft Store 包 `OpenAI.Codex` 不会因入口名为 `ChatGPT.exe` 被重复识别；`Codex CLI` 仍独立检测。
- 有效矩阵授权统一覆盖手机矩阵、基础获客、共享模板、飞书流转与 Skill 调用，错误提示不暴露内部能力键。
- Agent 首次成功流程需经用户确认才能沉淀为 Skill；第二次调用优先复用已验证步骤、脚本、模板和缓存。
- 手机低延迟视频仍使用 MediaProjection + MediaCodec H.264；USB 转发和视频通道是不同层，非聚焦设备的截图预览不称为实时流。
- 产品名称统一为“麓鸣”，使用完整麓鸣 Logo，启动界面原动画不变。

## 发布和验收边界

- 本任务生成候选安装包并推送功能分支，不合并 PR、不创建正式 Release、不更换正式桌面下载通道。
- Windows Sandbox、API 36 和 API 24 虚拟机需完成逐按钮回归；自动化和虚拟机不能替代实体机验收。
- USB 视频、热点/Wi-Fi 切换、Android 7/10/14+、多机并发、温升和长时间稳定性仍需实体机验收。
- PRoot companion 的独立分发、许可证告知和发布签名必须在正式发布前再次核验。
