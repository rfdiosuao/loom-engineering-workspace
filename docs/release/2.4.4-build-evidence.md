## 5. PRoot/Linux 与 Shizuku 边界

- 两份精确 APK 对 `openminis / proot / rootfs / alpine / debian / ubuntu / busybox / linux-runtime` 的 ZIP 条目扫描命中均为 `0`。
- 因此 2.4.4 **没有把手机小 Linux 放进 APK**；当前交付的是 clean-room Schema、workspace 隔离、资源预算、Native-first 路由、回退策略、供应链门禁和基准工具。
- Shizuku 只接入官方 API/Provider、用户本地授权和类型化策略；未内嵌 Shizuku、`rish`、Root/Sui shell，也未向模型、LAN 或第三方 Agent 开放任意命令执行。
- 虚拟机不能替代 Shizuku Binder、OEM MediaProjection、真实热点、USB 枚举/拔插、温升、功耗和多设备长稳证据。
