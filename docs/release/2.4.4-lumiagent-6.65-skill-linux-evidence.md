## 2. 已实现边界

- 设置页新增 Skill Center，列出内置 Linux Skill 与 Agent 沉淀的工作流 Skill。
- 成功、确定性、只读、DIRECT-only 的首次轨迹可安全激活，第二次走已有模板快路径；视觉、选择器和副作用任务继续执行原有多轮验证门禁。

- `agent.cli.batch`、任意 executable、argv、shell 和脚本入口均被拒绝。

- PRoot、loader、动态库和 Alpine rootfs 在安装前逐项 SHA-256 校验，使用 staging、健康检查、原子激活与回滚目录。
