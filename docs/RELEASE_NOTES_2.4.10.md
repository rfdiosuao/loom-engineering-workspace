# 麓鸣 2.4.10 / LumiAgent 6.67 发布说明

> 配套版本：麓鸣 Desktop `2.4.10`；LumiAgent `6.67-stability`（Android 7 为
> `6.67-stability-android7`），手机 versionCode `936`。本次不修改或重新构建手机端。

## 退出登录修复

- 修复授权租约锚点变化后，登录会话被错误判断为 `identityChanged`，导致退出登录永久被拦截的问题。
- 账号运行时身份现在优先以真实登录会话为准，授权租约只在会话身份缺失时作为后备。
- 退出前仍会停止 Agent、矩阵任务、手机事件同步、daemon 与 USB 会话；确有未完成任务时继续保持失败关闭策略。

## DeepSeek 与模型配置修复

- 修复模型目录刷新遇到临时 502/503/504 或网络超时时，缓存中仍有效的 DeepSeek 等模型也无法配置的问题。
- 只有与缓存模型目录精确匹配的模型才允许继续，随后仍必须通过 Codex Responses API 与原生工具调用验证。
- 缓存中不存在的模型、鉴权失败、权限不足和不兼容模型继续拒绝写入，避免把失效配置写进 Codex Desktop。

## 验收记录

- 新增授权租约变化但账号未变化的退出登录回归测试。
- 新增模型目录临时不可用时使用缓存目录并继续远程验证的回归测试。
- 保留账号切换隔离、后台任务清理、配置事务回滚和会话保护机制。
