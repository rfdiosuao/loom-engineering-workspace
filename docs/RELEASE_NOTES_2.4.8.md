# 麓鸣 2.4.8 / LumiAgent 6.67 发布说明

> 配套版本：麓鸣 Desktop `2.4.8`；LumiAgent `6.67-stability`（Android 7 为
> `6.67-stability-android7`），手机 versionCode `936`。本次不修改或重新构建手机端。

## ZPay 充值闭环修复

- 账号资料暂时使用安全快照时，支付服务仍会独立完成在线验证；服务端返回有效套餐和渠道后可直接创建扫码订单。
- 套餐目录请求与订单创建、查询、恢复使用独立请求序列，避免并发刷新导致未完成订单丢失。
- 应用重启后继续恢复未完成订单并复用原幂等请求标识，不重复创建订单。
- Bridge 会把超过收银台有效期且仍为 pending 的订单收敛为 expired；后续服务端确认真实到账时仍可更新为 paid。
- 服务端明确返回 ZPay readiness：已就绪、在线充值未启用、支付配置未确认或无可用收款渠道；客户端显示准确原因。

## 收款和安全边界

- 模型订阅继续使用 New API 原生 EPay → ZPay 作为唯一权威收款链路。
- PID、Key、签名字段和服务端访问令牌不进入桌面安装包、前端或普通日志。
- 支付成功只以服务端异步通知和原生订单状态为准；前台返回页不直接发放订阅。
- 商业矩阵授权与模型订阅保持独立，不因模型充值自动解锁矩阵设备权益。

## 部署与验收

- 生产 Bridge 已通过受控原子部署、自动备份、环境哈希不变、健康页、权益公钥、支付路由和订阅路由检查。
- 自动化覆盖账号安全快照、套餐加载、扫码创建、幂等恢复、订单过期和服务端支付状态诊断；自动化不替代真实商户小额验收。
