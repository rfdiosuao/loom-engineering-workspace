# LOOM 发布检查清单

## 来源与范围

- [ ] 发布提交是已审核的精确 SHA，不从脏工作树构建。
- [ ] PR 边界、风险域、回滚方式和未执行项已填写。
- [ ] 版本号、产物、签名和 Release 由发布负责人单独处理。

## 自动化门禁

- [ ] `.\scripts\invoke-reliability-gates.ps1 -Risk high -Ci`
- [ ] `.\scripts\verify.ps1 -Area workspace`
- [ ] Platform、Phone 和 Release 对应全量 CI 均通过。
- [ ] `git diff --check` 与敏感文件检查通过。

## 数据保护

- [ ] 覆盖升级保留账号、配置、历史会话和自定义 Provider。
- [ ] 诊断证据不含 API Key、Token、手机令牌和客户数据。
- [ ] 回滚路径及恢复上一版本的方法已验证。

## 外部验收

- [ ] 真实模型账号与上游接口已验收，或明确标记“未执行”。
- [ ] 实体手机和 Matrix soak 已验收，或明确标记“未执行”。
- [ ] Windows 商业可信签名已验证，或明确标记“未执行/开发证书”。
- [ ] 自动更新清单签名、下载、重启交接和回退已在目标环境验收。

未完成的外部验收不得由单元测试、模拟器、自签开发证书或历史结果替代。
