# 麓鸣 2.4.5 / LumiAgent 6.66 发布候选说明

> 当前配套版本：麓鸣 Desktop `2.4.5`；LumiAgent `6.66-stability`（Android 7 为
> `6.66-stability-android7`）；手机 `versionCode` 为 `935`。

## 本轮核心变化

### Agent 目录去重

- 用户界面只保留 `Codex Desktop`，按 Microsoft Store 包身份 `OpenAI.Codex` 识别；即使程序入口名为 `ChatGPT.exe`，也不会再生成独立的 ChatGPT Desktop 项。
- `Codex CLI` 继续作为独立 Agent 检测、安装、升级和配置。
- Grok Build、Pi、Goose 等 CLI Agent 保留独立兼容性探测、备份和回滚边界。

### 手机矩阵、获客、飞书与云模板共用授权

- 有效 `matrix.devices` 授权同时覆盖手机矩阵、基础获客、飞书流转、共享模板中心和 Skill 调用；不再向用户要求额外的获客、飞书或云模板商业授权。
- 飞书 OAuth、机器人、表格和文档权限只是连接与运行条件，不是第二份付费授权。
- 共享模板使用稳定 `template_id` 和版本号，支持搜索、启停、冲突检测、离线缓存、失败重试、回滚、审计和敏感变量脱敏。
- 获客空状态直接提供绑定手机、打开手机矩阵、选择模板和连接排查入口。

### Skill 中心与快速复用

- 桌面端新增 Skill 列表、详情、来源、版本、适用 Agent、调用次数、最近使用、启停、导入导出和删除入口。
- Agent 首次成功完成可复用流程后，必须由用户确认才能沉淀；第二次优先复用已验证步骤、脚本、模板和缓存。
- Skill 可关联共享模板，并由桌面 Agent、手机矩阵、获客任务和飞书流转统一调用；执行保留参数校验、超时、审计、回滚与脱敏。
- 仅借鉴 OpenMinis 的产品思路，未复制 GPLv3 代码。

### 真实账户状态与应用内扫码购买

- 登录、在线验证、模型、余额、用量、套餐、邀请码和授权均区分服务端在线数据与只读安全快照；离线快照不能绑定授权码、购买或同步模型。
- 麓鸣后端新增 Z-Pay/易支付 Provider Adapter，桌面端只向麓鸣后端创建订单，不保存商户 PID 或密钥。
- 应用内展示服务端真实套餐、价格、期限与权益；二维码内容与直达支付 URL 分开处理，“我已付款”只查询服务端订单状态。
- 权益仅在服务端完成签名、商户、订单、金额、渠道、nonce、成功状态和支付流水号校验，并在数据库事务中幂等提交后开通。
- 支付商户配置默认关闭；候选包不包含真实商户域名、PID 或密钥。未配置时明确显示暂未开放，并保留外部账户中心作为降级入口。
- 本候选不执行真实扣款、退款、结算或商户资料修改，也不把同步返回页当作支付成功证据。

## LumiAgent 6.66 与手机运行时边界

- 保留 Skill 中心、固定 Skill ID 与第一次学习/第二次确定性快速路径。
- PRoot/Linux 以独立安装的 `Lumi Linux Runtime` companion 提供，主 APK 不内置 PRoot 或 rootfs；companion 无 `INTERNET` 权限，只开放经过合同枚举的固定文本处理 Skill。
- Shizuku 继续采用用户本机主动授权的可选增强边界；未安装、停服、拒绝或撤权时自动保持标准模式，不开放任意 Shell。
- 聚焦手机低延迟视频继续使用 MediaProjection + MediaCodec H.264；USB 转发与视频通道是两层能力，非聚焦设备仍是截图预览而不是伪称实时流。

产品名称统一为“麓鸣”，使用完整麓鸣 Logo；启动界面原动画保持不变。

## 发布和验收边界

- 本任务只生成本地候选并推送功能分支；不合并 PR、不创建正式 Release、不更新正式下载通道。
- API 36 与 API 24 虚拟机需重新完成安装、配对、Skill 连续调用、PRoot companion、无网络权限和越权拒绝验收。
- 自动化与虚拟机不能替代实体机验收。USB 聚焦视频、热点/Wi-Fi 切换、Android 7/10/14+、多机并发、温升和长时间稳定性仍需实体机验收。
- PRoot companion 尚未通过商业发行所需的法律、发布签名和实体机性能门禁，不进入正式更新通道。
